# SNS — دمج جملة الموبايلات في النسخة الرئيسية

الإصدار مبني على نفس index.html اللي كان شغال على main بعد إصلاح الدخول. قسم جملة الموبايلات موجود تحت المشتريات والموردين ويستخدم جلسة SNS ومعرّف المحل المفتوح. مالك المحل يقدر يفعّل النشاط. الموظف في نفس المحل بيشوف القسم بعد التفعيل، حسب صلاحياته.

## التجهيز مرة واحدة

1. افتح مشروع `fatorty` في Supabase ثم **SQL Editor**.
2. للتأكد من وجود دوال النشاط، شغّل الاستعلام:

```sql
select
  to_regprocedure('public.sns_wholesale_status(uuid)') is not null as status_ready,
  to_regprocedure('public.sns_wholesale_enable(uuid,boolean)') is not null as enable_ready,
  to_regprocedure('public.sns_wholesale_read(uuid,text,jsonb,integer,uuid)') is not null as read_ready,
  to_regprocedure('public.sns_wholesale_command(uuid,uuid,text,jsonb)') is not null as write_ready;
```

3. لو فيه عمود `false`، شغّل محتوى ملف `supabase/SNS-Mobile-Wholesale-Phase0.sql` على مشروع `fatorty`. الملف ينشئ الوحدة ودوالها وينتظر تفعيل صاحب المحل من الواجهة.

## الرفع على GitHub

1. افتح الفرع `main` من مستودع `fatorty11`. اضغط **Add file → Upload files**.
2. ارفع **الملفات الثلاثة من مجلد github فقط** إلى جذر المستودع في نفس الـcommit:

| الملف | التغيير |
| --- | --- |
| `index.html` | إضافة القسم إلى القائمة وتوصيله بالمحل والجلسة الحاليين. |
| `wholesale.js` | الإعدادات والكتالوج والموردون والشراء والـIMEI والأرصدة الافتتاحية. |
| `sw.js` | تحديث إصدار كاش التطبيق وإضافة ملف واجهة الجملة. |

3. انتظر **Ready** على Vercel. افتح موقع SNS الرئيسي، ويفضّل فتح نافذة خفية في أول تجربة.
4. سجّل الدخول بحساب المالك. من القائمة افتح **المشتريات والموردون → جملة الموبايلات → تفعيل النشاط لهذا المحل**.

## اختبار القبول

| الاختبار | المتوقع |
| --- | --- |
| فتح النظام على الديسكتوب والموبايل والانتقال من القائمة | القسم يفتح داخل SNS وتبقى بيانات المحل الحالي. |
| إضافة مورد بالجنيه وشراء جهازين بـ٣١٬٠٠٠ لكل جهاز، مصاريف ٢٠٠، ضريبة صفر، دفعة ٤٠٬٠٠٠ | إجمالي ٦٢٬٢٠٠، مستحق ٢٢٬٢٠٠، وتكلفة كل جهاز ٣١٬١٠٠. |
| إدخال رقم IMEI مش صحيح أو مرتين في نفس الدفعة | خطأ واضح قبل إضافة السطر للمسودة. |
| فتح فاتورة الشراء من القائمة | يظهر تفصيل البنود وأرقام الأجهزة وكلفتها للمالية. |
| معاينة واستيراد رصيد افتتاحي لإكسسوار ١٠ وحدات بإجمالي ١٬٥٠٠ في مخزن فاضي | المعاينة تسبق الحفظ، وبعد الاعتماد يظهر متوسط ١٥٠. |
| فتح القسم بحساب كاشير في محل فعّل النشاط | يظهر المخزون بلا تكاليف، وشاشات الشراء وإدارة الموردين محجوبة. |

دورة الشراء والاستيراد والعزل اتجرّبت محليًا على PostgreSQL عبر PGlite. مسار القائمة اتجرّب في Chromium على ١٤٤٠×٩٠٠ و٣٩٠×٨٤٤، واختبارات الإقلاع والبيع والمخزون والمزامنة الأساسية نجحت. رفع الملفات وتشغيل SQL على حساب Supabase عندك وتجربة الدخول على الإنتاج خطوات عندك.

استيراد المرحلة الأولى يقبل CSV أو لصق خلايا Excel، والمشتريات تدعم دفعات نقدية وتحويل من الحسابات المسجلة. البيع بالجملة والتحصيل والمرتجعات لها المراحل التالية.
