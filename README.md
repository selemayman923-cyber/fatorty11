# SNS · مراجعة ما قبل تسليم العميل

النسخة مبنية على main بعد تصحيح اتصال الإنتاج بـfatorty، ومعاها دمج مخزون جملة الموبايلات. راجعت أحدث ملف منشور وقت بدء الشغل، وكان عليه إصلاح الدخول، وشملت الحزمة التحديثات التالية فوقه.

## الإصلاحات

- بعد أول دخول بحساب المالك، المحل اللي لسه محتاج إعداد يفتح شاشة اختيار القطاع والمجال، ثم يسأل عن اسم المحل، المنتجات أو الخدمات، وصفحة البداية. الاختيارات بتتسجل على مستوى المحل.
- عند تعذّر تحميل بيانات المحل الجديد، المستخدم بيشوف شاشة استعادة فيها إعادة التحميل وتسجيل الخروج. تأكيد الإيميل له رسالة واضحة. إذا لم يتأكد حفظ الإعداد على السحابة، الحالة بتظهر للمستخدم.
- لو فشل إنشاء العضوية وسبق إنشاء المحل، إعادة المحاولة تستخدم المحل اللي الحساب مالكه.
- العيادة وأدوات المواعيد وتقرير العيادة وتنبيه المواعيد تظهر للنشاط المناسب. بيانات العيادات القديمة التي تستخدم شاشة العيادة بلا تصنيف محفوظ ما زالت قابلة للعرض. المحل اللي نشاطه متحدد على تجارة يحتفظ ببياناته، وتختفي منه أدوات العيادة. إعدادات النشاط تعتمد على اختيار المجال للتحكم في ظهور العيادة.
- الموظف المدعو يبدأ من الشاشة المناسبة لدوره. المحل القديم اللي له نشاط محفوظ أو سجل تشغيل يرجع لشغله.
- قسم جملة الموبايلات بيستخدم المستخدم والمحل الحاليين، ويتفعّل من حساب المالك.

## الملفات والرفع

1. فك الضغط ثم افتح مجلد `github`.
2. ارفع `index.html` و`wholesale.js` و`sw.js` مع بعض في جذر فرع `main`.
3. بعد نشر Vercel، افتح [SNS](https://sns-business.vercel.app) في نافذة خفية للاختبار الأول.
4. لو دوال جملة الموبايلات اتركبت مسبقًا في `fatorty`، افتح القسم على طول. لو القسم قال إن قاعدة النشاط محتاجة تثبيت، يحتوي مجلد `supabase` على ملف المرحلة صفر وملف قراءة للتحقق من وجود الدوال. تثبيت قاعدة الجملة مستقل عن شاشة إعداد النشاط.

## قبول العميل

| التجربة | النتيجة المطلوبة |
| --- | --- |
| تسجيل حساب مالك جديد وتأكيد البريد عند طلبه | عند أول دخول تظهر شاشة اختيار المجال للمحل الجديد. |
| اختيار صيدلية أو أقمشة أو نشاط خدمات | تُحفظ الإعدادات وتظهر الأقسام المناسبة وتختفي العيادة وتنبيهاتها. |
| إغلاق الصفحة ثم الدخول من نافذة ثانية | يعاد فتح نفس المحل بإعداداته المحفوظة. |
| الدخول بمالك محل قائم ومراجعة فاتورة يعرفها | الفاتورة بنفس الرقم والقيمة، وشاشة أول إعداد لا تعترض الحساب. |
| دخول كاشير مدعو | يبدأ من نقطة البيع بصلاحياته، وحساب المالك وحده يقدر يغيّر نشاط المحل. |
| دورة شراء وبيع ومرتجع على بيانات اختبار | راجع الكمية قبل وبعد كل حركة والرصيد في الخزينة ورقم المستند. |
| فتح عيادة حقيقية مختارة كنشاط | المواعيد والتقارير الطبية ظاهرة حسب الدور. |

اتجرّبت رحلة إنشاء الحساب وتأكيد البريد وإكمال الإعداد على متصفحات محلية بجلسات Supabase محاكية، واتجرّبت سيناريوهات المحل القائم والكاشير وقطع تحميل المحل. راجع نتائج البريد والمزامنة في مشروعك الفعلي من حساب جديد قبل التسليم للعميل.
